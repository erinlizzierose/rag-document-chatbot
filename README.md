# Document Chatbot

A Phase 1 LangChain project: ask questions about a document using retrieval
augmented generation (RAG).

## What This Teaches

- Loading documents from local files
- Splitting text into chunks
- Creating embeddings
- Storing chunks in a local vector database
- Retrieving relevant context for a user question
- Asking an LLM to answer only from that context

## Project Shape

```text
data/              Documents to index
vectorstore/       Local Chroma database, generated by ingest.py
app.py             Streamlit chat app
ingest.py          Document loading and indexing script
requirements.txt   Python dependencies
```

## Setup

Create a virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Create your local environment file:

```bash
cp .env.example .env
```

Then edit `.env` and add your OpenAI API key:

```text
OPENAI_API_KEY=your_api_key_here
```

## Add A Document

Put a `.md`, `.txt`, or `.pdf` file in the `data/` folder.

This repo includes `data/sample_notes.md` so you can try the app immediately.

## Index The Document

Run:

```bash
python ingest.py
```

This creates a local Chroma vector store in `vectorstore/`.

## Start The Chatbot

Run:

```bash
streamlit run app.py
```

Then open the local URL shown in your terminal.

## How It Works

1. `ingest.py` loads the files in `data/`.
2. It splits the text into overlapping chunks.
3. It converts each chunk into an embedding.
4. It stores the chunks and embeddings in Chroma.
5. `app.py` retrieves relevant chunks for each question.
6. The chat model answers using only those chunks.
